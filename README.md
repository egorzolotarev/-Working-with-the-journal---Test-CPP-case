# -Working-with-the-journal---Test-CPP-case
Это документация по динамической библиотеке LibJournal, которая позволяет производить запись сообщений в журнал, а так же по консольному приложению App, которое использует Journal для многопоточной записи сообщений в текстовый файл.

### Бизнес логика
У каждого сообщения есть свой уровень важности, всего их 3 - SMALL, MIDDLE и HIGH.  Сообщения с уровнем важности меньшем чем дефолтный не записываются.
В журнале сообщения будут записываться в следующем формате:
LEVEL : YYYY-MM-DD HH:MM:SS : message

Библиотека предоставляет доступ к классу Journal, который пользователь использует для записи в журнал, перечислению ImportanceLevels и интерфйсу IWriter, реализации которого записывают сообщения. Подключается библиотека через build/lib/libjournal.so

## Journal
Для работы с Journal необходимо инициализировать его, задав дефолтный уровень важности и реализацию IWriter.

Класс Journal обладает следующими методами:
SetWriter - позволяет настраивать способ, которым будет производиться запись в журнал
SetImportanceLevel - позволяет менять дефолтный уровень важности у сообщений
Write - использует IWriter для записи в файл

## IWriter
IWriter - это интерфейс с методом Write.

### FileWriter
FileWriter - реализация IWriter для запись в файл по указанному пути.

## Приложние App
Приложение можно запустить через файл build/app/run_app. В качестве аргументов оно принимает путь к файлу для записи сообщений и дефолтный уровень важности.  
Для записи сообщения в файл введите "сообщение --LEVEL", где LEVEL это уровень важности SMALL/MIDDLE/HIGH. Уровень важности можете не писать, тгда он будет дефолтный.  
Для смены дефолтного уровня важности введите "--SET LEVEL".  
Для выхода из приложения введите "exit".

## Сборка
Требования:
- GCC с поддержкой C++17
- Make

Сборка библиотеки и приложения - make all  
Сборка библиотеки - make lib  
Сборка приложения - make app  
Очистка временных файлов(папка build) - make clean
